**University Event Management System (UEMS)**
** Project Overview:**
The University Event Management System (UEMS) is a web-based application designed to streamline the process of managing university events. It provides a centralized platform for students, faculty, and administrators to create, manage, approve, and participate in events efficiently.
The system eliminates manual event handling by offering role-based access, real-time updates, and an organized workflow for event proposals and approvals.
**Objectives**
Automate the event management process in universities
Reduce paperwork and manual coordination
Provide transparency in event approvals
Allow students to discover and register for events easily
**User Roles**
1. Admin
Approve or reject event proposals
Manage all events
View event statistics
2. Faculty
Create and submit event proposals
View approval status
3. Student
View approved events
Register for events
Track participation
